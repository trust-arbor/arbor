# EP-07 — Recall gate: audience containment on provenance visibility

**Phase:** C · **Depends:** EP-06 · **Spec:** removes `(planned)` from ENGAGE-13, ENGAGE-14
**Apps:** `arbor_memory` (gate), `arbor_comms` or `arbor_persistence` (visibility lookup — hierarchy decides, see below).

## Goal

The disclosure hazard closes: a memory learned in a `:private` engagement cannot
surface into a `:group`/`:public` one. This is the first enforcement of
`Engagement.visibility`.

## Deliverables

1. `Arbor.Memory.DisclosureGate` (in `arbor_memory`):

   ```elixir
   @spec allow?(entry_provenance :: %{source_engagement_id: String.t() | nil},
                target :: %{engagement_id: String.t() | nil,
                            visibility: atom() | nil}) :: boolean()
   ```

   Rules (v1 coarse-tag containment):
   - source stamp absent → allow (legacy exemption, ENGAGE-13 wording).
   - target engagement absent/nil (non-conversational context) → allow only
     `:public`-source and unstamped; treat internal cognition as `:internal`
     audience (document).
   - else compare on the order `:private < :group < :internal? no —`
     the lattice: `:public` ⊒ everything; `:internal` sources surface only into
     `:internal` targets; otherwise allow iff
     `rank(source) >= rank(target)` with rank `:private=0, :group=1, :public=2`
     (source must be at least as wide as target — never widen).
   - visibility lookup failures/unknown ids → deny for stamped entries
     (fail closed), allow for unstamped.
   - Cache lookups per-call-batch (a plain map accumulator — no ETS yet).
2. Wire the gate into every recall path that feeds prompt context (from your
   Read-first enumeration): filter AFTER retrieval scoring, BEFORE
   context/prompt assembly, passing the target engagement's id+visibility from the
   Session turn context (the Session knows `current_engagement_id`; resolve its
   visibility once per turn).
3. Visibility widening audit (ENGAGE-14): find where engagement visibility can be
   changed (`grep -rn "visibility" apps/arbor_comms/lib/arbor/comms/engagement_store.ex apps/arbor_persistence/lib/arbor/persistence/engagement_store.ex`).
   If a mutation path exists, wrap it: widening (rank increase) emits
   `engagement.visibility.widened` signal with before/after; if NO mutation path
   exists, add `update_visibility/2` to the comms store as the only sanctioned
   mutator (emitting the signal), so future widening can't dodge the audit.
