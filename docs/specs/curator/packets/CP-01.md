# CP-01 — `arbor_curator` app, item schema, store, canonicalizer

**Phase:** 1 · **Depends:** — · **Blocks:** CP-02, CP-03, CP-04 · **Spec:** CURATE-3, CURATE-6, CURATE-7, CURATE-8
**App:** `arbor_curator` (new, L4), `arbor_persistence` (schema + migration only).

## Goal

The domain substrate: a new umbrella app holding the curator item store with a
guarded status lifecycle, plus URL canonicalization/dedupe. After this packet,
items can be created, deduplicated, and transitioned — nothing fetches or scores yet.

## Deliverables

1. New umbrella app `apps/arbor_curator` — library-only (no supervision tree):
   `mix.exs` with exactly the deps above; no `Application` module needed.
2. `Arbor.Persistence.Schemas.CuratorItem`
   (`apps/arbor_persistence/lib/arbor/persistence/schemas/curator_item.ex`) +
   migration creating `curator_items`:
   - `id` UUID pk; `url` (:text); `canonical_url` (:text, **unique index**);
     `title`; `source` (:string); `sender` (:string); `received_at` (:utc_datetime_usec);
     `status` (:string, default `"queued"`, index);
     `content_excerpt` (:text); `summary` (:text); `why` (:text);
     `score` (:integer); `verdict` (:string);
     `integration_ideas` ({:array, :string}, default []); `topics` ({:array, :string}, default []);
     `error` (:text); `retry_count` (:integer, default 0);
     `fetched_at`, `assessed_at`, `surfaced_at` (:utc_datetime_usec); `timestamps()`.
   - Changeset validates `status` in `~w(queued fetched assessed surfaced archived failed)`
     and `verdict` (when present) in `~w(must_read skim skip)` (CURATE-6, CURATE-13 shape).
3. `Arbor.Curator.Canonicalizer` (`apps/arbor_curator/lib/arbor/curator/canonicalizer.ex`):
   `canonicalize(url :: String.t()) :: {:ok, String.t()} | {:error, :invalid_url}` —
   lowercase scheme+host, drop fragment, drop `utm_*`/`fbclid`/`gclid` query params
   (preserve the rest, stable order), normalize trailing slash on empty-path roots;
   reject non-http(s) schemes (CURATE-3).
4. `Arbor.Curator.Store` (`apps/arbor_curator/lib/arbor/curator/store.ex`), on
   `Arbor.Persistence.Repo`:
   - `add_item(attrs) :: {:ok, item} | {:ok, :duplicate} | {:error, changeset}` —
     canonicalizes, inserts with `on_conflict: :nothing` on `canonical_url`;
     duplicate MUST NOT reset the existing row (CURATE-3).
   - `transition(item_or_id, to_status, attrs \\ %{}) :: {:ok, item} | {:error, term}` —
     legal graph: `queued→fetched→assessed→surfaced→archived`, and
     `queued|fetched|assessed → failed`; illegal transition returns
     `{:error, {:invalid_transition, from, to}}` without writing (CURATE-7). Sets
     `fetched_at`/`assessed_at`/`surfaced_at` on first entry into that status only
     (CURATE-8).
   - `record_failure(item, error_text) :: {:ok, item}` — increments `retry_count`,
     stores `error`; when `retry_count` reaches
     `config :arbor_curator, :max_fetch_attempts` (default 3), transitions to `failed`.
   - Queries: `next_queued(limit)` (oldest first, status `queued`),
     `fetched_batch(limit)` (status `fetched`, oldest first),
     `assessed_unsurfaced()` (status `assessed`, score desc).
5. Config defaults in `config/config.exs`:
   `config :arbor_curator, max_fetch_attempts: 3, max_content_chars: 20_000`.
6. **Coverage-tool fix (small, adjacent, intentional):** in
   `apps/arbor_common/lib/mix/tasks/arbor/spec/coverage.ex`, change
   `@specs_glob "docs/specs/*.md"` to `"docs/specs/**/*.md"`. The current glob only
   sees top-level spec files and silently misses `docs/specs/voice/VOICE-1.0.md`,
   `docs/specs/engagements/ENGAGE-1.0.md`, and this spec. Expect the coverage
   report to newly list VOICE/ENGAGE statements after this change — that is the
   fix working, not a regression you caused.

## Tests

`apps/arbor_curator/test/` (DB-backed tests follow whatever sandbox/repo setup the
persistence tests use — grep `Arbor.Persistence.Repo` under `apps/arbor_persistence/test`
for the pattern; mirror it):

- `@tag spec: "CURATE-3"` — canonicalization table test (tracking params stripped,
  fragment dropped, case folded, non-http rejected); `add_item` twice with URL
  variants of the same page → one row, second call `{:ok, :duplicate}`, status of
  the first row unchanged.
- `@tag spec: "CURATE-6"` — schema rejects an invalid status; all six statuses valid.
- `@tag spec: "CURATE-7"` — every legal edge succeeds; a representative set of
  illegal edges (`queued→surfaced`, `surfaced→failed`, `failed→fetched`) returns
  `{:error, {:invalid_transition, _, _}}` and the row is unchanged.
- `@tag spec: "CURATE-8"` — transition into `fetched` sets `fetched_at`; a contrived
  second pass through the same status does not change the original timestamp.
