# PP-03 — Engine verification: fail-closed for stdlib/shared graphs

**Phase:** A · **Depends:** PP-02 · **Blocks:** PP-04, PP-07 · **Spec:** PLUGIN-8, 11, 12 (tamper half), 13, 14, 15
**App:** `apps/arbor_orchestrator` (L7).

## Goal

No stdlib/shared DOT executes without a verified signature. Unsigned
agent-authored DOT still runs — under the caller's own authority only. This is
the security gate the 2026-07-04 decision demands; it closes the "chat turn and
heartbeat ARE stdlib DOT files on disk, nothing enforces governance against a
direct file edit" gap.

## Deliverables

1. `Arbor.Orchestrator.ArtifactVerification`
   (`lib/arbor/orchestrator/artifact_verification.ex`):
   - `classify_source(path_or_opts)` → `:stdlib | :shared | :agent | :unknown`.
     Stdlib = loaded from `specs/pipelines/**` / `priv/templates/**`; shared =
     shared-library dir (config `:arbor_orchestrator, :shared_artifact_dirs`,
     empty until PP-15); agent = runtime-authored (Engine opt `source: :agent`).
   - `verify(dot_source_bytes, sidecar_envelope)` — canonical re-serialize
     (parse → `DotSerializer.serialize(graph, strip_internal: true)`) → sha256 →
     `Arbor.Security.verify_artifact/2`. Returns `:ok | {:error, reason}`.
     **TOCTOU rule:** the bytes verified are the bytes handed to the compiler —
     pass the verified binary through, never re-read the file after verify.
   - Sidecar convention: `<file>.dot` + `<file>.sig.json` (PP-02 envelope).
2. Wire into `RunAuthorization`: runs classified `:stdlib`/`:shared` require
   `verify/2` success before the first node; failure → refuse run with a
   structured error, emit `security.artifact.verification_failed` via
   `Arbor.Signals.emit` (artifact/file, reason, caller). `:agent` runs proceed
   unsigned but MUST carry the caller's authority/taint — assert the existing
   behavior, don't rebuild it.
3. Config rollout switch `:arbor_orchestrator, :artifact_verification` —
   `:enforce | :log_only | :off` (default `:log_only` in this packet; flipping to
   `:enforce` is PP-04's job after stdlib graphs are signed). `:off` only for test
   envs. `log_only` emits the same signal with `enforced: false`.
4. Signing coverage for the tree: extend `mix arbor.artifact.sign` usage docs +
   add `mix arbor.pipeline.sign_stdlib` (orchestrator task) that signs every
   `.dot` under `specs/pipelines/` with the system key
   (`ensure_artifact_signing_key("system")`), writing sidecars. Idempotent.
5. Unsignable-until-review guard: `verify/2` rejects (when `:enforce`) any
   envelope whose manifest/provenance carries `source: "llm_compiled"` or
   `source: "sanitizer_modified"` unless `admission_decision_id` is present
   (PLUGIN-15; council wiring itself is PP-08 — here it's just the envelope check).

## Tests

`apps/arbor_orchestrator/test/arbor/orchestrator/artifact_verification_test.exs`:
- `@tag spec: "PLUGIN-11"` — stdlib-classified run with no/invalid sidecar is
  refused under `:enforce`; proceeds under `:log_only` with signal.
- `@tag spec: "PLUGIN-12"` — bit-flipped `.dot` (valid envelope) refused, signal
  payload carries `:digest_mismatch`.
- `@tag spec: "PLUGIN-13"` — `:agent` run executes unsigned; a graph loaded from
  a non-stdlib path claiming stdlib classification is refused.
- `@tag spec: "PLUGIN-14"` — the binary compiled is byte-identical to the binary
  verified (instrument through the code path, not by re-reading the file).
- `@tag spec: "PLUGIN-8"` — sign via canonical serialize → verify succeeds even
  after cosmetic reformat of the source file (comments/whitespace), because both
  sides canonicalize.
- `@tag spec: "PLUGIN-15"` — `llm_compiled` provenance without admission id
  refused under `:enforce`.
