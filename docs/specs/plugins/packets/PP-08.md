# PP-08 — Council admission gate for shared/stdlib artifacts

**Phase:** B · **Depends:** PP-07 · **Blocks:** PP-15 · **Spec:** PLUGIN-29, 30, 15 (completes)
**App:** `apps/arbor_artifacts` (+ install pipeline edit in orchestrator specs).

## Goal

Nothing enters the shared library or gets stdlib authority without a recorded
council decision. Pre-generation `.dot` review is wired in as the cheap screening
gate.

## Read first

- `apps/arbor_consensus/lib/arbor/consensus.ex` — `decide/2`, `ask/2`,
  `get_decision/2` (programmatic entry points; there is no `await/2` — poll
  `get_decision/2` or use the synchronous `decide/2`)
- `apps/arbor_actions/lib/arbor/actions/council.ex` — `Council.Consult`,
  `Council.ReviewChange` (existing council actions; reuse the invocation style)
- PP-07 `install-artifact.dot` (as merged) — the `admission_gate` branch
- PP-03 Deliverable 5 (envelope check for `llm_compiled` provenance)
- `.arbor/decisions/2026-07-04-dot-signing-and-adapt-node-policy.md` — review
  gate requirement

## Deliverables

1. `Arbor.Artifacts.Admission`
   (`apps/arbor_artifacts/lib/arbor/artifacts/admission.ex`):
   - `request(manifest, envelope, opts)` — builds a review proposal (manifest
     summary, capability claims, payload digest list, `.dot` sources inline for
     pre-generation review) and submits via `Arbor.Consensus.decide/2`
     (synchronous path) or `ask/2` + `get_decision/2` polling, timeout from opts.
   - Returns `{:ok, decision_id} | {:error, :rejected, reasons} | {:error, term()}`.
   - Persists decision id into the registry entry + receipt
     (`admission_decision_id`).
2. Signing tie-in: `Arbor.Security.sign_artifact/2` gains an option
   `authority_class: :shared` that REFUSES unless `admission_decision_id` is
   present in the manifest provenance (completes PLUGIN-15's chain: no shared
   signature without decision). Local/first-party class unchanged.
3. Install pipeline: replace PP-07's placeholder admission branch with an
   `artifact.admission` Jido action calling `Admission.request/3`. Shared-class
   installs route through it; local installs skip (branch condition on manifest
   metadata `class=shared`).
4. Pre-generation screening (PLUGIN-30): `Admission.request` includes each
   bundled `.dot` source and the capability declarations in the proposal body so
   councils review INTENT (prompts, write targets, commands) before code review.
   Document in moduledoc that this is screening, not a guarantee — the
   fail-closed layers stay authoritative.
5. Config: `:arbor_artifacts, admission: :council | :auto_approve_local_dev`
   (the latter only usable when `Mix.env() != :prod`; refuse otherwise).

## Tests

- `@tag spec: "PLUGIN-29"` — shared-class install without decision refuses at
  admission; with a (test-double) approving council, proceeds and the decision
  id lands in receipt + registry entry. `sign_artifact(authority_class:
  :shared)` without decision id refuses.
- `@tag spec: "PLUGIN-15"` — end-to-end: `llm_compiled`-provenance artifact +
  approved decision verifies under `:enforce`; same artifact without decision
  refused (extends PP-03 test).
- `@tag spec: "PLUGIN-30"` — proposal body contains the `.dot` source and
  capability claims (assert on the submitted proposal, consensus faked).
- Rejection path: council rejects → status `:failed`, reasons surfaced, no side
  effects past staging.

Use a consensus test double (see how arbor_consensus tests fake evaluators);
never spin real LLM councils (`:llm` tag not allowed here).

internals. Do not build a second review path for non-artifact skills — that
migration is a later series (PLUGIN-4 note).
