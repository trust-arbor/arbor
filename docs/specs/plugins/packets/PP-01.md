# PP-01 — Artifact contracts (`Arbor.Contracts.Artifact.*`)

**Phase:** A · **Depends:** — · **Blocks:** PP-02..PP-15 · **Spec:** PLUGIN-1, 2, 3, 5, 6 (partial: types + canonical encoding)
**App:** `apps/arbor_contracts` (L0).

## Goal

The shared vocabulary of the unified artifact channel: manifest, signature
envelope, receipt, and deterministic canonical encoding — pure data + pure
functions, no processes, no signing.

## Read first

- `docs/arbor/CONTRACT_RULES.md` (what belongs in contracts)

  `signing_payload/1` deterministic-encoding pattern you are replicating

  typedstruct conventions, redacted Inspect
- `apps/arbor_common/lib/arbor/common/registry_base.ex` — `validate_plugin_namespace/2`

## Deliverables

1. `Arbor.Contracts.Artifact.Manifest`
   (`apps/arbor_contracts/lib/arbor/contracts/artifact/manifest.ex`), typedstruct:
   - `kind :: :plugin | :template` (`:skill` reserved — accept, document as reserved)
   - `name :: String.t()` — `~r/^[a-z][a-z0-9_]*$/` (the registry prefix; entries
     it registers are `"<name>.<entry>"`)
   - `version :: String.t()` (semver string, validated shape only)
   - `author :: String.t()` (principal id)
   - `description :: String.t()`
   - `requires_capabilities :: [String.t()]`, `provides_capabilities :: [String.t()]`
   - `payload :: [%{path: String.t(), sha256: String.t()}]` — relative paths only;
     reject `..` and absolute paths in `validate/1`
   - `registrations :: %{optional(:actions) => [%{name: String.t(), module: String.t()}],
     optional(:handlers) => [%{type: String.t(), module: String.t()}],
     optional(:templates) => [String.t()],
     optional(:signal_hooks) => [%{pattern: String.t(), module: String.t()}],
     optional(:ui) => %{nav: [map()], views: %{String.t() => String.t()}}}`
     (modules as strings — contracts must not reference upper-layer modules)
   - `provenance :: %{optional(:run_id) => String.t(), optional(:source) => String.t()}`
   - `new/1`, `validate/1` (returns `{:ok, t} | {:error, [reason]}`; enforces name
     regex, path safety, namespace rule: every `registrations` entry name/type/path
     is prefixed `"<name>."` or `"/<name>"` for ui view paths)
2. `Arbor.Contracts.Artifact.Manifest.canonical_encoding/1` —
   `@spec canonical_encoding(t()) :: binary()`. Deterministic: sorted keys,
   payload sorted by path, no optional whitespace. Property: equal structs ⇒
   identical binaries; any field change ⇒ different binary. Follow
   `Capability.signing_payload/1`'s approach (explicit field list — NOT
   `Jason.encode!` of the raw struct).
3. `Arbor.Contracts.Artifact.SignatureEnvelope`
   (`.../artifact/signature_envelope.ex`): `artifact_name`, `artifact_version`,
   `signer` (principal id), `key_id`, `algorithm` (`:ed25519`),
   `manifest_sha256`, `signature :: binary()`, `signed_at`. `new/1`, plus
   Jason encoding with `signature`/digests base64-encoded. No key material ever.
4. `Arbor.Contracts.Artifact.Receipt` (`.../artifact/receipt.ex`): records every
   side effect — `artifact_name`, `artifact_version`, `installed_at`,
   `installed_by`, `admission_decision_id :: String.t() | nil`,
   `files_written :: [String.t()]`, `registrations` (same shape as manifest
   section, as-applied), `capability_grants :: [String.t()]` (grant ids),
   `signal_hooks :: [String.t()]` (subscription ids), `ui :: map()`,
   `forced :: boolean()`. `new/1`, `validate/1`, Jason round-trip.
5. `Arbor.Contracts.Artifact.Status` — `:installed | :active | :inactive |
   :failed | :revoked` with `valid_transition?/2`
   (installed→active/failed, active→inactive/revoked, inactive→active/revoked;
   revoked terminal; failed→installed only via reinstall).
