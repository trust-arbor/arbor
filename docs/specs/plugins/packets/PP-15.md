# PP-15 — Shared library: index, publish, semantic discovery (Stage 2)

**Phase:** D · **Depends:** PP-12, PP-08 · **Blocks:** — · **Spec:** PLUGIN-38, 39
**App:** `apps/arbor_artifacts`.

## Goal

The thinnest honest "marketplace": a shared-library directory of signed bundles
with an embedding-backed index, publish gated by admission. Local/multi-node
filesystem first; a remote registry protocol is future work (the cold-start risk
in `.arbor/decisions/2026-07-06-red-team-the-central-bet.md` argues against
building more before demand exists).

## Read first

- PP-12 Bundle (as merged) — `package/inspect/import`
- PP-08 Admission — decision ids; `sign_artifact(authority_class: :shared)`
- `apps/arbor_orchestrator/lib/arbor/orchestrator/preprocessor.ex` + its

## Deliverables

1. Library layout: `Arbor.Artifacts.Library` over config
   `:arbor_artifacts, library_dirs: [...]` (list of dirs, first writable is the
   publish target):
   ```
   <library_dir>/<name>/<version>/<name>-<version>.arbor-artifact
   <library_dir>/index.json          (manifest summaries + embedding vectors)
   <library_dir>/revocations.json    (mirrored from RevocationStore on publish/revoke)
   ```
2. `publish(bundle_path)` — inspect (PP-12 safety), verify signature is
   shared-class (which itself proves admission, PP-08), verify not revoked,
   copy into layout, update index entry (embed `name + description +
   capability strings` via the embedding facade; store vector + summary).
   Refuse unsigned/local-class bundles (PLUGIN-39).
3. `search(query, opts)` — embed query, cosine top-k over index + substring
   fallback when embeddings unavailable (degrade gracefully, flag in result);
   returns manifest summaries with provenance + capability claims (enough to
   review before install). `install_from_library(name, version \\ :latest)` →
   PP-12 `import`.
4. Mix tasks: `mix arbor.artifact.publish <bundle>`,
   `mix arbor.artifact.search "<query>"`,
   `mix arbor.artifact.install <name>@<version>` (extends PP-07's task to
   resolve from library dirs when the arg isn't a path).
5. Revocation propagation: `revocations.json` refreshed on publish and by
   `mix arbor.artifact.revoke` (PP-04) when a library dir is configured;
   `install_from_library` consults it in addition to the local RevocationStore.

## Tests

- `@tag spec: "PLUGIN-39"` — publish refuses a local-class-signed bundle;
  accepts shared-class (admission decision id present, faked council);
  installed-from-library artifact carries the decision id in its receipt.
- `@tag spec: "PLUGIN-38"` — search: seeded 3-artifact library, semantic query
  matches the right artifact with embeddings faked deterministic; embedding
  facade down → substring fallback works and result flags degraded mode.
- Revocation: revoke → `install_from_library` refuses even when the bundle file
  is still present.
- Multi-dir precedence: same name in two dirs → first dir wins for read;
  publish only to the writable target.

## Out of scope

HTTP registry protocol, payments/accounts, install-count telemetry, web UI for
browsing (future artifact — it should itself be a plugin), federation. Do not
loosen import verification for library-sourced bundles ("trusted dir" is not a
thing — every install re-verifies).
