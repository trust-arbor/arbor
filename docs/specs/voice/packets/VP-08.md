# VP-08 — Phone loop: earbuds via phone-local STT/TTS

**Phase:** 2 · **Depends:** VP-07 · **Spec:** removes `(planned)` from VOICE-25, VOICE-26, VOICE-27, VOICE-28
**App:** `arbor_voice` (uses `arbor_comms` primitives).

## Goal

The actual use case: walk in public, PTT/VAD through earbuds, phone does STT/TTS
locally, core runs the front-desk loop. Raw audio never leaves the phone — the
backend gets TEXT turns (the prototype's proven text path), so this packet needs no
PCM streaming.

## Read first

- `apps/arbor_comms/lib/arbor/comms/channels/voice.ex` — the verified phone
  primitives and their exact return shapes: `buddie_listen/3` (earbud VAD),
  `listen/3`, `speak/3` (TTS, `:voice` 0-7), `toast/2`, `ping/1`, and the
  rpc/timeout conventions (`rpc_timeout = timeout + 5_000`).
- `apps/arbor_comms/lib/arbor/comms/channels/voice/session.ex` — the OLD island
  turn loop. You are REPLACING its role for this path, not extending it; note its
  loop/backoff/toast patterns (they're good) and its `Arbor.Agent.Manager.chat`
  bypass (which is exactly what we're NOT doing).
- `apps/arbor_voice/lib/arbor/voice/session.ex` — `text_turn/2` (VP-04/05).
- `.arbor/roadmap/1-brainstorming/phone-store-and-forward-percepts.md` — the
  control-plane semantics table (why stale responses are dropped).

## Deliverables

1. `Arbor.Voice.Audio.Phone` (`apps/arbor_voice/lib/arbor/voice/audio/phone.ex`):
   thin, injectable wrapper over `Arbor.Comms.Channels.Voice` (module resolved via
   app env for tests): `listen(node, mode, seconds)` (mode ∈
   `:buddie_listen | :listen | :stream_listen`), `speak(node, text, opts)`,
   `reachable?(node)`, `toast(node, msg)`.
2. `Arbor.Voice.PhoneLoop` (`.../phone_loop.ex`) — GenServer:

   ```elixir
   # start_link opts: :phone_node (required), :voice_session (pid/name, required),
   #   :mode (:ptt | :vad, default :ptt), :listen_mode (default :buddie_listen),
   #   :listen_seconds (default 8), :stale_after_ms (default 30_000), :tts_voice
   # API: trigger_turn(server) (the PTT "button"), start_vad(server), stop(server)
   ```

   Turn: `listen` → empty transcript = no-op (VAD re-arms; PTT returns :no_speech) →
   `VoiceSession.text_turn` → verdict handling: `{:speak, s}`/`{:speak_truncated, s}`
   → staleness check (VOICE-26): if `now - turn_start > stale_after_ms` OR
   `reachable?` fails, DROP speech, record `%{"dropped" => "stale"}` via a
   `voice.phone.response_dropped` signal, `toast` a marker; else `speak(s)`.
   `{:screen_only, s}` → `speak(s)` (s is already the non-specific pointer) + toast.
   Failures (VOICE-28): rpc/listen/speak errors → `toast` + `voice.phone.error`
   signal + (VAD mode) `Process.send_after` re-arm with the old island's 2 s
   backoff; never a silent crash-loop (use `:transient` restart + give_up counter
   emitting a final loud signal).
   PTT default (VOICE-27): `:vad` must be explicitly requested at start or via
   `start_vad/1`.
   Raw-audio invariant (VOICE-25): this module never touches PCM; the only backend
   input is the transcript via `text_turn` — assert in a test that the FakeBackend
   received only `send_text` (never `send_audio`) in phone mode.
3. Mix task `Mix.Tasks.Arbor.Voice.Phone`:
   `./bin/mix arbor.voice.phone --agent <id> --node beamapp@<ip> [--vad] [--seconds 8]`
   — wires VoiceSession + PhoneLoop; PTT mode reads Enter as the trigger (the
   earbud-button → trigger investigation is a marked TODO in the task's moduledoc,
   NOT this packet).

## Tests (all `:fast` via fakes; nothing touches a real node)

- `@tag spec: "VOICE-25"` — phone mode: fake backend saw `send_text` only; fake
  phone wrapper saw exactly one `speak` per successful turn.
- `@tag spec: "VOICE-26"` — turn exceeding `stale_after_ms` (fake session delays):
  no `speak`, one `response_dropped` signal, one toast.
- `@tag spec: "VOICE-27"` — default mode is PTT; `listen` is called only on
  `trigger_turn`; `start_vad` begins self-re-arming turns.
- `@tag spec: "VOICE-28"` — listen error → toast + error signal + re-arm (VAD) /
  error return (PTT); N consecutive failures → give-up signal, loop stopped.
