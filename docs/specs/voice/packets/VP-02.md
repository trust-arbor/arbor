## Deliverables

1. `apps/arbor_voice/` — standard umbrella app with supervisor
   (`Arbor.Voice.Application`, initially no children beyond a `Registry` named
   `Arbor.Voice.Registry`). Umbrella deps, exactly:
   `arbor_contracts, arbor_common, arbor_signals, arbor_comms, arbor_llm, arbor_ai,
   arbor_orchestrator, arbor_agent` (all `in_umbrella: true`). Add `jason`. Mirror
   the mix.exs shape of `arbor_commands`.
2. `Arbor.Voice.RealtimeBackend` behaviour (`apps/arbor_voice/lib/arbor/voice/realtime_backend.ex`):

   ```elixir
   @type session :: term()            # backend-opaque
   @type tool_decl :: map()           # backend-native tool schema (name/description/parameters)
   @type event ::
           {:input_transcript, String.t()}
         | {:output_text_delta, String.t()}
         | {:output_audio, binary()}          # PCM16 chunk (rate per backend meta)
         | {:tool_call, %{id: String.t(), name: String.t(), arguments: map()}}
         | {:turn_done, %{text: String.t()}}
         | {:error, term()}

   @callback open(opts :: keyword()) :: {:ok, session()} | {:error, term()}
   @callback configure(session(), %{optional(:instructions) => String.t(),
             optional(:tools) => [tool_decl()], optional(:audio) => map()}) ::
             {:ok, session()} | {:error, term()}
   @callback send_text(session(), String.t()) :: {:ok, session()} | {:error, term()}
   @callback send_audio(session(), binary()) :: {:ok, session()} | {:error, term()}
   @callback send_tool_result(session(), call_id :: String.t(), output :: String.t()) ::
             {:ok, session()} | {:error, term()}
   @callback recv(session(), timeout()) :: {:ok, session(), event()} | {:error, term()}
   @callback close(session()) :: :ok
   @callback meta(session()) :: %{backend: atom(), mode: :cloud | :local,
             input_rate: pos_integer() | nil, output_rate: pos_integer() | nil}
   ```

   Document each callback (RFC-2119-free, plain `@doc`). Enumerate error atoms you
   introduce; `{:error, term()}` is acceptable only for transport-level failures.
3. Config seam: `Arbor.Voice.Config` with `backend_module/0`
   (`Application.get_env(:arbor_voice, :backend, Arbor.Voice.Backend.XaiRealtime)`)
   and `user_id/0` (`Application.get_env(:arbor_voice, :user_id)` — see VP-04 for
   how the value is chosen). Follow the Config-module pattern referenced by
   CONTRACT_RULES §8-9.
