# VP-07 — Desk audio loop + `mix arbor.voice.talk`

**Phase:** 1 (exit) · **Depends:** VP-05 · **Blocks:** VP-08 · **Spec:** VOICE-13 (call-site half), VOICE-32
**App:** `arbor_voice`.

## Goal

Talk to Arbor at the desk: press Enter, speak, hear the answer. Turn-based PTT via
ffmpeg/ffplay (the proven path); Membrane comes later, not here.

## Read first

- `apps/arbor_agent/lib/arbor/agent/prototypes/xai_voice_orchestrator.ex` —
  `converse_from_mic/2` and `play_audio/1` (exact ffmpeg avfoundation record args:
  16 kHz mono s16le; ffplay 24 kHz playback args; device listing hint in the @doc).
- `apps/arbor_voice/lib/arbor/voice/session.ex` (VP-04/05 state).
- An existing mix task for style: `ls apps/arbor_common/lib/mix/tasks/arbor/` and
  read one small one.

## Deliverables

1. `Arbor.Voice.Audio.Mac` (`apps/arbor_voice/lib/arbor/voice/audio/mac.ex`):
   - `record(seconds, opts)` → `{:ok, pcm16_binary} | {:error, term}` (ffmpeg,
     prototype args; `:device` opt).
   - `play(pcm16_24k_binary)` → `:ok | {:error, term}` (ffplay via a temp file, as
     the prototype does).
   - `available?/0` — both binaries on PATH.
2. `Arbor.Voice.Session.audio_turn(server, pcm16 :: binary())` — like `text_turn/2`
   but `send_audio/2`; collects `{:output_audio, _}` chunks; returns
   `{:ok, %{reply: text, verdict: verdict, audio: pcm_or_nil, input_transcript: text}}`.
   TTS/audio-output rule (VOICE-13): the collected backend audio may be played ONLY
   when the Speakable verdict on the reply text is `{:speak, _}` or
   `{:speak_truncated, _}`... but backend audio corresponds to the un-rendered reply.
   v1 policy (document in moduledoc): when verdict is `:speak` play backend audio
   as-is; when `:speak_truncated` or `:screen_only` DISCARD backend audio and (until
   a TTS path for rendered text exists on desk) print the speakable string — the
   spec's no-bypass rule is what matters, not audio at any cost. Telemetry
   (VOICE-32): emit `[:arbor_voice, :turn]` measurements
   `%{ack_ms: nil | int, first_audio_ms: int | nil, total_ms: int}` per turn (ack is
   nil until earcons exist; measure first `{:output_audio,_}` arrival).
3. `Mix.Tasks.Arbor.Voice.Talk` (`apps/arbor_voice/lib/mix/tasks/arbor/voice/talk.ex`):
   `./bin/mix arbor.voice.talk --agent <agent_id> [--seconds 6] [--device :default] [--text]`
   — starts (or reuses) the registered VoiceSession, then loops: prompt
   "[Enter=talk N s, t <msg>=text turn, q=quit]"; records, runs `audio_turn`, plays
   per the rule above, prints the input transcript + speakable string every turn.
   `--text` skips audio entirely (works over SSH / in CI-less environments).

## Tests

  running them — extract argv builders as pure functions) — `:fast`.
- `@tag spec: "VOICE-13"` — `audio_turn` with FakeBackend: `:screen_only` verdict
  discards audio (returned `audio: nil`), `:speak` keeps it; assert via scripted
  events.
- `@tag spec: "VOICE-32"` — telemetry event emitted with the three keys per turn.
- Mix task: `:external`-tagged smoke that runs `--text` mode against FakeBackend
  config (assert one loop iteration via IO capture with scripted stdin).
